## Coordinate Specification (2000 x 1414 @ 72 DPI)

All text is dynamically fitted to avoid overflow, rendered in dark charcoal (`#1F1F26` / `rgb(0.12, 0.12, 0.15)`), using `Montserrat-Bold`.
